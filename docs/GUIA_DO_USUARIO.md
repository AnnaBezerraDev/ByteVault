# Guia do Usuário — BYTEVAULT

Bem-vindo ao **BYTEVAULT**, seu ambiente de produtividade e cofre pessoal de conhecimentos técnicos.

---

## 🧭 Atalhos Globais de Teclado
- **`Ctrl + K`**: Abre a **Pesquisa Global**. Digite qualquer termo para pesquisar instantaneamente em Projetos, Snippets, Comandos, Anotações, Bugs e Tags.
- **`Esc`**: Fecha a pesquisa global ou janelas modais.
- **`Enter`**: Abre o registro selecionado na busca rápida.

---

## 📚 Como Utilizar os Módulos

### 1. Painel Inicial (Dashboard)
Oferece métricas reais da sua base:
- Total de projetos cadastrados e em desenvolvimento.
- Contagem de snippets de código, comandos de CLI e anotações técnicas.
- Alerta em destaque de bugs ainda não resolvidos.
- Histórico recente de atividades e acesso rápido aos registros favoritados.

### 2. Módulo de Projetos
- Cadastre seus projetos de software com nome, descrição, linguagens e status.
- Clique no ícone de pasta para abrir diretamente a pasta local no Explorer.
- Clique no ícone de link para abrir o repositório Git no seu navegador padrão.

### 3. Módulo de Snippets (Trechos de Código)
- Armazene códigos reutilizáveis em C#, Python, SQL, TypeScript, Bash, etc.
- Edição com syntax highlighting profissional usando **AvalonEdit**.
- Clique em **Copiar** para transferir o código exatamente como escrito para sua área de transferência com confirmação instantânea.
- Use a opção **Duplicar** para criar variações de snippets existentes.

### 4. Módulo de Comandos
- Armazene comandos longos ou complexos organizados por ferramenta (Git, Docker, npm, PowerShell, Linux).
- Cópia segura com 1 clique para colar no seu terminal.

### 5. Anotações em Markdown
- Escreva documentações, resumos de estudos e arquiteturas com formatação rica.
- Alterne entre o modo de edição e a **Visualização Prévia** renderizada em tempo real.

### 6. Diário de Bugs
- Ao encontrar um erro difícil, registre o título, o log do erro original e a solução aplicada.
- Vincule um ou mais snippets de solução ao bug para recuperação futura.
- Marque como **Resolvido** para manter o controle dos seus aprendizados.

### 7. Tags e Favoritos
- Classifique qualquer item com tags para agrupamento transversal.
- Marque com uma estrela itens essenciais para visualizá-los diretamente na aba de **Favoritos**.

### 8. Configurações e Portabilidade
- Crie backups compactados em `.zip` contendo toda a sua biblioteca.
- Exporte seus dados em **JSON**, notas em **Markdown (.md)**, snippets em **TXT** ou relatórios em **CSV**.
